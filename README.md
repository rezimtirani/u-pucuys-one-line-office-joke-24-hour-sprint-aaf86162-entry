Entry for the make.fun bounty [One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162).

`main.py` writes one single-line joke about office life (at most 200
characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Standard library only,
no network, no files besides the output.

## The joke

> The office fridge has a sign saying 'your food, your responsibility',
> right above the sandwich someone stole in 2019.

## Run

```sh
python3 main.py
```
